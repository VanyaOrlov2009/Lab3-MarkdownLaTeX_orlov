## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

#### Markdown — это простой язык разметки, который позволяет форматировать текст с помощью обычных символов (например, знаков #, **, *).

#### Markdown применяется везде, где нужно быстро и просто оформлять текст, не отвлекаясь на сложные визуальные редакторы вроде Word.
##### Документация и IT
##### Мессенджеры и чаты
##### Базы знаний и заметки
##### Сайты и блоги

#### Markdown нужен разработчикам, чтобы писать документацию без мышки, легко отслеживать её изменения в Git, читать как простой текст и автоматически превращать в красивые веб-страницы на GitHub.
